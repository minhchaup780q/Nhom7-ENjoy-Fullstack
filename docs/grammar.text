Danh sách các ngữ pháp có thể xây dựng câu với từ vựng Pre A1

1/ Tên ngữ pháp: Nouns (Singular and plural, countable and uncountable, names)
Examples: Would you like an orange? Lemons are yellow. Pat has six mice. I eat rice for lunch. Nora is my friend.
Cách sử dụng: Chủ ngữ + Động từ + (mạo từ/số đếm) + Danh từ. -> Danh từ số nhiều + to be + Tính từ. -> Tên riêng + to be + (đại từ sở hữu) + Danh từ.

2/ Tên ngữ pháp: Adjectives (Including possessive adjectives)
Examples: He's a small boy. His name is Yusef.
Cách sử dụng: Đại từ/Chủ ngữ + to be + (mạo từ) + Tính từ + Danh từ. -> Tính từ sở hữu + Danh từ + to be + Tên riêng.

3/ Tên ngữ pháp: Determiners
Examples: It's a banana. This is an apple. Put the hat on the boy's head. I want some milk. These books are blue.
Cách sử dụng: Đại từ chỉ định (This/These/It) + to be + Từ hạn định (a/an/some) + Danh từ.

4/ Tên ngữ pháp: Pronouns (Including demonstrative, personal, possessive, interrogative, and 'one')
Examples: This is my car. Can you see me? Which is Anna? Yes, please. I'd like one. This is mine! Is that yours?
Cách sử dụng: Đại từ chỉ định + to be + (tính từ sở hữu) + Danh từ. -> Đại từ sở hữu (mine, yours) đứng cuối câu để thay thế cho cụm danh từ.

5/ Tên ngữ pháp: Verbs (Present simple - Positive, negative, question, imperative, short-answer)
Examples: Nick is happy. I don't like eggs. Eat your lunch! Is that your sister? Yes, it is.
Cách sử dụng: Chủ ngữ + Động từ (nguyên mẫu hoặc thêm s/es) + Tân ngữ. -> Câu phủ định: Chủ ngữ + don't/doesn't + Động từ nguyên mẫu. -> Mệnh lệnh: Động từ nguyên mẫu + (tính từ sở hữu) + Danh từ.

6/ Tên ngữ pháp: Present continuous (not with future reference)
Examples: What are you doing? The cat's sleeping.
Cách sử dụng: Chủ ngữ + to be + Động từ thêm đuôi -ing.

7/ Tên ngữ pháp: Can for ability
Examples: The baby can wave.
Cách sử dụng: Chủ ngữ + can + Động từ nguyên mẫu.

8/ Tên ngữ pháp: Can for requests/permission
Examples: Can I have some birthday cake?
Cách sử dụng: Can I + have + (từ chỉ số lượng) + Danh từ + ?

9/ Tên ngữ pháp: Have (got) for possession
Examples: Have you got a pen? She hasn't got a dog.
Cách sử dụng: Chủ ngữ + have/has (not) + got + (mạo từ) + Danh từ. -> Câu hỏi: Have/has + Chủ ngữ + got + (mạo từ) + Danh từ + ?

10/ Tên ngữ pháp: Adverbs
Examples: I'm colouring it now. My grandma lives here. She lives here too.
Cách sử dụng: Chủ ngữ + Động từ + (Tân ngữ) + Trạng từ (now, here, too).

11/ Tên ngữ pháp: Conjunctions
Examples: I've got a pen and a pencil.
Cách sử dụng: (mạo từ) + Danh từ 1 + and + (mạo từ) + Danh từ 2.

12/ Tên ngữ pháp: Prepositions of place and time
Examples: Put the clock next to the picture. We go to school in the morning.
Cách sử dụng: Động từ + (mạo từ + Danh từ) + Giới từ (next to, in) + (mạo từ) + Danh từ chỉ vị trí/thời gian.

13/ Tên ngữ pháp: Question words
Examples: Who is that man? Where is Alex?
Cách sử dụng: Từ để hỏi (Who, Where) + to be + (đại từ chỉ định) + Danh từ/Tên riêng + ?

14/ Tên ngữ pháp: Impersonal you
Examples: How do you spell that?
Cách sử dụng: Từ để hỏi + do you + Động từ nguyên mẫu + Tân ngữ + ?

15/ Tên ngữ pháp: Have + obj + inf
Examples: Lucy has a book to read.
Cách sử dụng: Chủ ngữ + have/has + (mạo từ) + Danh từ (đóng vai trò tân ngữ) + to + Động từ nguyên mẫu.

16/ Tên ngữ pháp: ing forms as nouns
Examples: Swimming is good.
Cách sử dụng: Động từ thêm đuôi -ing (đóng vai trò Chủ ngữ) + to be + Tính từ.

17/ Tên ngữ pháp: Let's
Examples: Let's go to the zoo!
Cách sử dụng: Let's + Động từ nguyên mẫu + (giới từ) + (mạo từ) + Danh từ.

18/ Tên ngữ pháp: Like + v + ing
Examples: I like swimming.
Cách sử dụng: Chủ ngữ + like/likes + Động từ thêm đuôi -ing.

19/ Tên ngữ pháp: There is/There are
Examples: There is a monkey in the tree. There are some books on the table.
Cách sử dụng: There is/There are + (mạo từ/từ chỉ số lượng) + Danh từ + giới từ + (mạo từ) + Danh từ chỉ vị trí.

20/ Tên ngữ pháp: Would like + n or v
Examples: I would like some grapes. Would you like to colour that ball?
Cách sử dụng: Chủ ngữ + would like + (từ chỉ số lượng) + Danh từ. -> Câu hỏi: Would you like + to + Động từ nguyên mẫu + (đại từ chỉ định) + Danh từ + ?

21/ Tên ngữ pháp: Story about + ing
Examples: This is a story about playing football.
Cách sử dụng: story about + Động từ thêm đuôi -ing + (Danh từ).

22/ Tên ngữ pháp: What (a/an) + adj + n
Examples: What a good dog! What beautiful fish!
Cách sử dụng: What + (a/an) + Tính từ + Danh từ!
